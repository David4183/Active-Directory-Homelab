# Active-Directory-Homelab
##  Overview
This project was conducted to built a virtualized Windows Active Directory develop hands-on experience with Windows Server administration, Active Directory Domain Services, DNS, networking, user management, and Windows client domain integration.

The lab simulates a small enterprise environment using VirtualBox and multiple Windows virtual machines.
##  Environment
This project demonstrates hands-on experience building and managing a Windows Active Directory environment. The lab simulates a real-world business network where users, devices, and policies are centrally managed by an IT administrator.
